For a browser-downloaded DMG in `~/Downloads`, compare `shasum -a 256 "$HOME/Downloads/Trident-1.0.0-macos-universal.dmg"` with the DMG's entry in the release's `SHA256SUMS`. Only if they match, run `xattr -d com.apple.quarantine "$HOME/Downloads/Trident-1.0.0-macos-universal.dmg"` **before opening the DMG**. Then open the DMG and drag Trident to Applications. Before opening Trident the first time, run `xattr -dr com.apple.quarantine /Applications/Trident.app`. These steps apply only to this download and app; the Homebrew cask handles quarantine for you. Verify Linux downloads with `sha256sum -c SHA256SUMS`.
